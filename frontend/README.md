# Frontend (React + Vite)

Placeholder frontend scaffold for SunDevil AR Waypoint.

## Planned Responsibilities

- Camera access in browser
- OCR with Tesseract.js
- Room-to-node matching
- Route rendering and AR-style directional overlays

## Commands

```bash
npm install
npm run dev
npm run build
npm run preview
```
