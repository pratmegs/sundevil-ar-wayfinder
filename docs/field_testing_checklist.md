# Field Testing Checklist

## Route Data Collection

- [ ] Collect room numbers on route.
- [ ] Note hallway turns and intersections.
- [ ] Update map file after testing.

## OCR Validation

- [ ] Test lighting across bright, dim, and mixed conditions.
- [ ] Record OCR behavior (correct reads, misses, false reads).
- [ ] Track confidence trends for plaque types/fonts.

## Post-Run Maintenance

- [ ] Reconcile observed route notes with graph edges.
- [ ] Add/adjust room plaque mapping entries.
- [ ] Log unresolved OCR edge cases for future tuning.
