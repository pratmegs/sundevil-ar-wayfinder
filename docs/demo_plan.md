# Demo Plan

## App Setup

Open the React + Vite app in a browser and confirm camera permissions are available for the demo device.

## Destination Selection

Select a destination room from the future destination list.

## Camera Plaque Scan

Point the camera at a real McCord Hall room plaque and run browser-based OCR detection.

## Path Update

Map the detected room plaque to the current graph node and update the route to the selected destination.

## Final Arrival Screen

Show an arrival state when the detected location matches the destination or final route node.
